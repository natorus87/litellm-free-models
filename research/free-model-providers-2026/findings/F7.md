# F7: Verify ElevenLabs and Cartesia API endpoint compatibility, exact free-plan commercial-use and attribution/license restrictions, Germany/EU availability or data residency, and whether LiteLLM natively supports them.

## Findings

### [1] ElevenLabs' EEA terms, which cover Germany, restrict every free user and their output to non-commercial purposes.
- quote: "Free User”), you may only use the Services for non-commercial purposes"
- url: https://elevenlabs.io/terms-of-use-eu
- source_type: primary
- published: 2026-03-31
- confidence: high

### [2] Publishing ElevenLabs output made on the free plan requires attribution using “elevenlabs.io” or “11.ai”, while the free plan grants no commercial license.
- quote: "you must attribute it to ElevenLabs"
- url: https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform
- source_type: primary
- published: unknown
- confidence: high

### [3] ElevenLabs exposes most API endpoints to free-plan accounts, consuming the account's included credits rather than requiring a separate paid API tier.
- quote: "Most of our API endpoints are available for all plans, including the free plan."
- url: https://elevenlabs.io/docs/help-center/technical/how-much-does-it-cost-to-use-the-api
- source_type: primary
- published: unknown
- confidence: high

### [4] ElevenLabs' standard service stores customer data in the United States; EU storage and the EU API host are Enterprise-only, and strict EU-only processing additionally requires API use plus Zero Retention Mode.
- quote: "As a standard, ElevenLabs’ customer data is hosted/stored in the U.S."
- url: https://elevenlabs.io/docs/overview/administration/data-residency
- source_type: primary
- published: unknown
- confidence: high

### [5] LiteLLM natively implements ElevenLabs audio transcription and TTS adapters, translating OpenAI transcription requests to `/v1/speech-to-text`, using `ELEVENLABS_API_KEY`, and exposing an ElevenLabs TTS transformation in the same provider package.
- quote: "Translates from OpenAI's `/v1/audio/transcriptions` to ElevenLabs's `/v1/speech-to-text`"
- url: https://github.com/BerriAI/litellm/blob/main/litellm/llms/elevenlabs/audio_transcription/transformation.py
- source_type: primary
- published: unknown
- confidence: high

### [6] Cartesia's renewable Free plan includes 20,000 credits monthly, approximately 27 minutes of Sonic-3.6 TTS and 1 hour 51 minutes of Ink-2 STT, but commercial-use licensing begins only with the $5/month Pro plan.
- quote: "Everything in Free, plus Commercial use license"
- url: https://www.cartesia.ai/pricing
- source_type: primary
- published: unknown
- confidence: high

### [7] Cartesia's terms confirm that the default license is personal and non-commercial unless the subscription tier expressly permits commercial use; the public terms do not state an attribution requirement for non-commercial Free output.
- quote: "for your personal, non-commercial use only"
- url: https://www.cartesia.ai/legal/terms
- source_type: primary
- published: 2024-06-14
- confidence: medium

### [8] Cartesia can be accessed from Germany at the user's own initiative, but the default service is controlled from the United States and dedicated EU data-resident inference is Enterprise-only.
- quote: "Dedicated regional deployments are available to Cartesia Enterprise customers"
- url: https://docs.cartesia.ai/enterprise/regional-endpoints
- source_type: primary
- published: unknown
- confidence: high

### [9] Cartesia is not OpenAI-audio-endpoint compatible: its API requires `POST /tts/bytes` or `POST /stt` plus a dated `Cartesia-Version` header, and LiteLLM v1.97.0 contains no native Cartesia provider adapter, so integration needs custom translation or a future LiteLLM adapter.
- quote: "Always send a `Cartesia-Version` header"
- url: https://docs.cartesia.ai/use-the-api/api-conventions
- source_type: primary
- published: unknown
- confidence: high

## Dead ends
- LiteLLM documentation search returned no official Cartesia provider page; the v1.97.0 installed package and current upstream `litellm/llms` tree were inspected instead.
- Cartesia's public terms do not explicitly discuss attribution, so “no attribution required” cannot be stated as a guaranteed license conclusion.
- Neither provider documents a Germany-specific ban; the meaningful limitation is default U.S. processing versus paid Enterprise regional residency.

## Suggested follow-ups
- Ask Cartesia support to confirm in writing whether Free-plan output may be publicly distributed without attribution.
- Confirm whether ElevenLabs Free includes the specific STT and TTS models intended for the proxy, because “most” API endpoints is not an exhaustive entitlement list.
- Prototype a minimal Cartesia-to-OpenAI audio translation adapter and assess whether maintaining it is worth the non-commercial-only Free quota.
