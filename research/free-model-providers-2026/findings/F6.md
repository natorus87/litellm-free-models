# F6: Find and verify any legitimate renewable free image-generation, image-editing, or video-generation API outside the 13 existing providers, explicitly checking Pollinations, Freepik, Stability, fal, Replicate, Segmind, Runware, and similar candidates for API terms and quotas.

## Findings

### [1] Pollinations is the only checked candidate with a legitimate mechanism for renewable no-cash API usage: users can earn Pollen credits through quests, and the unified API covers image generation, image editing, and text-to-video/image-to-video.
- quote: "Pollen Quests — earn Pollen by completing Quests"
- url: https://github.com/pollinations/pollinations
- source_type: primary
- published: 2026-08-18
- confidence: high

### [2] Pollinations is not an unconditional free inference service: its current API uses Pollen credits at roughly $1 per Pollen, and server-side secret keys consume the account balance despite having no request-rate limit.
- quote: "Pollen credits — simple pay-as-you-go system ($1 ≈ 1 Pollen)"
- url: https://github.com/pollinations/pollinations
- source_type: primary
- published: 2026-08-18
- confidence: high

### [3] Pollinations exposes an OpenAI-compatible API at `https://gen.pollinations.ai/v1`, so its renewable quest-earned allowance is technically integrable into the proxy, but available models and per-model Pollen prices must be queried live.
- quote: "The API is OpenAI-compatible, so the official OpenAI SDKs work out of the box"
- url: https://github.com/pollinations/pollinations
- source_type: primary
- published: 2026-08-18
- confidence: high

### [4] Stability AI offers only a one-time 25-credit API starter balance, worth $0.25 at its stated conversion of one credit to $0.01; no renewable API allowance is documented.
- quote: "Get started with 25 free credits."
- url: https://platform.stability.ai/pricing
- source_type: primary
- published: unknown
- confidence: high

### [5] fal is not a free provider: all successful image and video outputs consume prepaid credits, while only server errors and queue waiting time are free.
- quote: "fal uses a prepaid credit model. You purchase credits in advance and they are drawn down as you use the platform."
- url: https://fal.ai/docs/documentation/model-apis/pricing
- source_type: primary
- published: unknown
- confidence: high

### [6] Replicate does not document a renewable free API tier; public image and video models are metered per output or execution time, including FLUX Schnell at $3 per 1,000 images and Wan 2.1 video from $0.09 per output second.
- quote: "Most models are billed by the time they take to run."
- url: https://replicate.com/pricing
- source_type: primary
- published: unknown
- confidence: high

### [7] Runware provides only $2 in one-time new-user trial credits and thereafter charges pay-as-you-go, with its official range for image generation at $0.0006–$0.24 per image.
- quote: "new users receive $2 in free credits"
- url: https://runware.ai/pricing
- source_type: primary
- published: 2026
- confidence: high

### [8] Segmind's nominal “Free Account” is not a renewable inference allowance: its Flexible API plan requires a minimum $10 recharge and successful generations consume purchased credits.
- quote: "Recharge with as low as $10 to get started."
- url: https://docs.segmind.com/docs/account/pricing-and-billing
- source_type: primary
- published: unknown
- confidence: high

### [9] Freepik's formerly documented $5 API starter credit was a one-time onboarding promotion, not a renewable quota, and the old Freepik API quickstart now redirects to Magnific documentation where API access is account- or enterprise-controlled.
- quote: "Contact your designated Magnific representative to request API access."
- url: https://docs.magnific.com/quickstart
- source_type: primary
- published: unknown
- confidence: medium

## Dead ends
- Freepik's old official quickstart search result still mentions a free API key plus $5 starter credit, but the URL now redirects to Magnific and no current renewable Freepik API quota could be verified.
- Stability AI's Community License permits qualifying users to self-host core models for free, but that is a model license rather than a hosted inference API allowance.
- Segmind labels the initial account “Free Account,” but its current official pricing requires purchased credits and therefore does not meet the renewable-free criterion.
- No current official renewable free API quota was found for fal, Replicate, Runware, Stability, Freepik/Magnific, or Segmind.
