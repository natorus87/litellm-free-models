# F5: Verify Z.AI and Together AI free-model signup requirements, payment requirements, quotas/rate limits, API compatibility, geographic availability, and proxy-relevant usage terms.

## Findings

### [1] Z.AI currently lists three genuinely zero-priced API models: the text models GLM-4.7-Flash and GLM-4.5-Flash, plus the multimodal-input vision model GLM-4.6V-Flash; image generation, video generation, and speech recognition remain paid.
- quote: "GLM-4.7-Flash | Free | Free | Free | Free"
- url: https://docs.z.ai/guides/overview/pricing
- source_type: primary
- published: unknown
- confidence: high

### [2] Z.AI's official onboarding requires registration or login followed by API-key creation, but its API quick start does not state that a card, deposit, or paid subscription is required before calling the zero-priced models.
- quote: "Register or Login. Create an API Key"
- url: https://docs.z.ai/guides/develop/openai/python
- source_type: primary
- published: unknown
- confidence: medium

### [3] Z.AI is OpenAI-compatible for chat-completions clients through `https://api.z.ai/api/paas/v4/`, although its documentation warns that some interface differences remain.
- quote: "Z.AI provides interfaces compatible with OpenAI API"
- url: https://docs.z.ai/guides/develop/openai/python
- source_type: primary
- published: unknown
- confidence: high

### [4] Z.AI's international terms do not exclude Germany or the EU, but expressly prohibit access from Iran, North Korea, Cuba, Crimea, Donetsk, and Zaporizhzhia and require sanctions compliance for end users.
- quote: "Iran, North Korea, Cuba, Crimea, Donetsk, or Zaporizhzhia"
- url: https://docs.z.ai/legal-agreement/terms-of-use
- source_type: primary
- published: 2026-04-14
- confidence: high

### [5] Z.AI's normal API terms expressly permit integrating the API into applications and downstream systems for end users, so an application-facing LiteLLM proxy is supported in principle if its operator manages users, abuse, security, disclosure, and legal compliance.
- quote: "integrate the Services into your applications"
- url: https://docs.z.ai/legal-agreement/terms-of-use
- source_type: primary
- published: 2026-04-14
- confidence: high

### [6] Together AI is not a genuinely no-payment provider: it offers no free trial and requires a minimum $5 credit purchase plus a positive prepaid balance before any API call, even when a catalog entry has a $0 inference price.
- quote: "Together AI does not currently offer free trials."
- url: https://docs.together.ai/docs/billing-credits
- source_type: primary
- published: unknown
- confidence: high

### [7] Together AI no longer publishes stable RPM/TPM quotas for serverless inference; limits are dynamic per organization and model, depend on live capacity and recent successful traffic, and over-limit calls return HTTP 429.
- quote: "Limits are set per organization and per model"
- url: https://docs.together.ai/docs/serverless/rate-limits
- source_type: primary
- published: unknown
- confidence: high

### [8] Together AI exposes an OpenAI-shaped `POST /v1/chat/completions` endpoint with bearer authentication, making its serverless text models straightforward to route through LiteLLM after the mandatory deposit.
- quote: "https://api.together.ai/v1/chat/completions"
- url: https://docs.together.ai/docs/serverless/rate-limits
- source_type: primary
- published: unknown
- confidence: high

### [9] Together AI's terms permit API use but prohibit transferring, reselling, licensing, or offering the service on a standalone basis, so a private/internal proxy is materially safer than exposing Together capacity as a public or third-party proxy service.
- quote: "otherwise offer the Services on a standalone basis"
- url: https://www.together.ai/terms-of-service
- source_type: primary
- published: 2026-05-19
- confidence: high

## Dead ends
- Z.AI publishes no fixed numeric free-model RPM, TPM, daily-request, or token quota in the fetched public documentation; its FAQ redirects authenticated users to a per-account rate-limit dashboard.
- No official Together AI country allowlist or Germany/EU availability table surfaced; the terms only require compliance with applicable export law.
- Together AI's zero-priced catalog entry does not overcome the platform-wide minimum $5 purchased-credit gate, so it cannot qualify for this repository's exclusively no-payment provider set.

## Suggested follow-ups
- Create a Z.AI account from Germany without adding payment details, then call `glm-4.7-flash` and `glm-4.6v-flash` while recording response rate-limit headers.
- Ask Z.AI support whether its unpublished free-model quotas are stable enough for automated proxy routing and whether commercial downstream access has any additional approval requirement.
- Ask Together AI support whether the $5 platform-access purchase is refundable and whether any $0 model consumes, reserves, or merely requires that positive balance.
