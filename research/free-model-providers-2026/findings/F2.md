# F2: Image and multimodal providers offering free API quotas for image generation, editing, vision, video, or document understanding.

## Findings

### [1] Azure Vision in Foundry Tools offers a renewable F0 image-analysis allowance of 5,000 transactions per month at 20 transactions per minute, covering tagging, object/people detection, OCR/Read, captions, smart crops, and moderation-related features.
- quote: "5,000 free transactions per month"
- url: https://azure.microsoft.com/en-us/pricing/details/computer-vision/
- source_type: primary
- published: unknown
- confidence: high

### [2] Azure Vision separately lists 5,000 free multimodal-embedding transactions per month for text and image embeddings, making it a strong candidate for image-search or cross-modal retrieval rather than generative imaging.
- quote: "Image Analysis Multimodal Embeddings"
- url: https://azure.microsoft.com/en-us/pricing/details/computer-vision/
- source_type: primary
- published: unknown
- confidence: high

### [3] Google Cloud Vision gives the first 1,000 units of each image-analysis feature per month free, including text/document OCR, labels, faces, landmarks, logos, SafeSearch, crop hints, web detection, and object localization.
- quote: "the first 1000 units used each month are free"
- url: https://cloud.google.com/vision/pricing
- source_type: primary
- published: unknown
- confidence: high

### [4] OCR.space has a renewable free document-understanding API allowance of 25,000 requests per month, additionally capped at 500 requests per day per IP address.
- quote: "Requests/month | 25,000"
- url: https://ocr.space/ocrapi
- source_type: primary
- published: unknown
- confidence: high

### [5] OCR.space's free API accepts images and multipage PDFs but limits inputs to 1 MB and PDFs to three pages; searchable-PDF output is available with a watermark and no SLA.
- quote: "PDF Page Limit | 3"
- url: https://ocr.space/ocrapi
- source_type: primary
- published: unknown
- confidence: high

### [6] remove.bg provides a renewable image-editing allowance of 50 background-removal API calls per month and supports direct upload or URL input with output up to 50 megapixels.
- quote: "Your first 50 API calls per month are on us"
- url: https://www.remove.bg/api
- source_type: primary
- published: unknown
- confidence: high

### [7] Sightengine's free API plan has no time limit and exposes image moderation, AI-image/deepfake detection, OCR, quality analysis, profile validation, and age estimation, but its public page does not state the free operation count.
- quote: "Yes you can. There is no time limit."
- url: https://sightengine.com/pricing
- source_type: primary
- published: unknown
- confidence: medium

### [8] Sightengine caps the free plan at one request per second and excludes video processing, so it is a renewable image-analysis candidate rather than a free video-analysis provider.
- quote: "Capacity Maximum requests per second | 1 req/s"
- url: https://sightengine.com/pricing
- source_type: primary
- published: unknown
- confidence: high

### [9] Amazon Rekognition Image is a trial rather than a permanent free tier: for 12 months after account creation it permits 1,000 images per month in its face/search and detection/OCR API groups.
- quote: "free tier period lasts 12 months"
- url: https://aws.amazon.com/rekognition/pricing/
- source_type: primary
- published: unknown
- confidence: high

### [10] Amazon Rekognition Video likewise provides 60 minutes of video analysis per month only during the 12-month free-tier period, covering labels, moderation, faces, celebrities, text, and person paths.
- quote: "includes 60 free minutes of video analysis per month"
- url: https://aws.amazon.com/rekognition/pricing/
- source_type: primary
- published: unknown
- confidence: high

### [11] For AWS accounts created from 15 July 2025, the alternative free-plan promotion is up to $200 in credits with a six-month free-plan window, so it must not be modeled as renewable zero-cost capacity.
- quote: "up to $200 in AWS Free Tier credits"
- url: https://aws.amazon.com/rekognition/pricing/
- source_type: primary
- published: 2025-07-15
- confidence: high

## Dead ends
- Clarifai's current official pricing page redirected in a way the fetcher rejected; the only accessible pricing PDF was stale and was not used.
- Roboflow search results surfaced only a 2023 community statement about 1,000 monthly inference credits, not current primary pricing evidence.
- Stability AI's official developer-pricing page rendered no extractable terms, so no free image-generation credit claim was retained.
- No current primary evidence was found for a durable free API quota from Replicate, fal, Segmind, Runware, or other dedicated image/video-generation hosts; apparent offers were trials or signup credits.
- Google's Gemini image/video generation was not counted as a new provider because Google AI Studio is already integrated, and current official pricing marks video generation as paid-tier availability.
- Azure's pricing selector needs a live Germany/West Europe account check because the static table warns that some F0 offers can be unavailable in a selected region.

## Suggested follow-ups
- Verify Azure Vision F0 creation and the 5,000-transaction quota in a Germany/West Europe subscription before integration.
- Create a Sightengine free account to record its actual monthly operation quota and EU data-processing region.
- Test whether OCR.space and remove.bg can be cleanly exposed through LiteLLM custom endpoints despite not using an OpenAI-compatible schema.
