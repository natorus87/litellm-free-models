# F4: Integration and risk validation: LiteLLM/OpenAI compatibility, exact free-tier restrictions, regional/payment requirements, and misleading "free" claims for the strongest candidates.

## Findings

### [1] Scaleway Generative APIs is the cleanest EU-hosted integration candidate because its Serverless API works with the OpenAI Python SDK at the exact base URL `https://api.scaleway.ai/v1`.
- quote: "This example shows you how to start using Generative APIs in your Python code, via the OpenAI Python SDK."
- url: https://www.scaleway.com/en/docs/generative-apis/quickstart/
- source_type: primary
- published: 2026-04-16
- confidence: high

### [2] Scaleway's free allowance covers at most 1,000,000 model tokens and 60 audio-transcription minutes, then automatically becomes paid usage with a 1,000-token minimum billing unit; the documentation specifies no periodic reset, so it must not be represented as a renewable free tier without further confirmation.
- quote: "After reaching this limit, you will be charged"
- url: https://www.scaleway.com/en/docs/generative-apis/faq/
- source_type: primary
- published: 2026-04-13
- confidence: high

### [3] Scaleway currently hosts every Serverless model in Paris and promises that `api.scaleway.ai` will remain Europe-hosted, making it regionally suitable for an individual developer in Germany, although single-region processing is guaranteed only for Dedicated Deployment.
- quote: "All Serverless models are currently hosted in a secure data center located in Paris, France"
- url: https://www.scaleway.com/en/docs/generative-apis/faq/
- source_type: primary
- published: 2026-04-13
- confidence: high

### [4] SambaNova's rate-limit documentation still describes a no-payment-method Free Tier for five chat models at 20 RPM, 20 requests/day, and 200,000 tokens/day, which would be renewable daily if operational.
- quote: "Free Tier: Applied when there is no payment method linked"
- url: https://docs.sambanova.ai/docs/en/models/rate-limits
- source_type: primary
- published: unknown
- confidence: high

### [5] SambaNova's live plans page directly contradicts its rate-limit documentation by requiring a payment method and purchased credits before the first request, so SambaNova must fail the genuinely-free admission test until a fresh German signup and live inference prove otherwise.
- quote: "Add a payment method and purchase credits to run your first requests."
- url: https://cloud.sambanova.ai/plans
- source_type: primary
- published: unknown
- confidence: high

### [6] Even if SambaNova's documented free access works, its preview models are evaluation-only, capacity-limited, and explicitly removable at short notice, so only production models should enter durable fallback chains.
- quote: "may be removed at short notice"
- url: https://docs.sambanova.ai/docs/en/models/rate-limits
- source_type: primary
- published: unknown
- confidence: high

### [7] Jina exposes embeddings at the OpenAI-shaped `POST https://api.jina.ai/v1/embeddings` endpoint, making a generic LiteLLM `openai/` deployment plausible, and its free key is limited to 100 RPM, 100,000 TPM, and two concurrent requests.
- quote: "Free: 100 RPM, 100K TPM, 2 concurrent requests"
- url: https://jina.ai/en-US/embeddings/
- source_type: primary
- published: unknown
- confidence: high

### [8] Jina's strongest genuinely zero-price exception, `jina-embeddings-v4`, is deliberately throttled and restricted to research/non-commercial use under the Qwen Research License, so calling it generally free would be materially misleading for app or business workloads.
- quote: "Users should not expect high-volume or production-level throughput"
- url: https://jina.ai/en-US/embeddings/
- source_type: primary
- published: unknown
- confidence: high

### [9] Voyage AI offers a large but finite account-level trial rather than a renewable free tier: the first 200 million tokens are free on current general/code embedding models and rerankers, while several specialty models receive 50 million.
- quote: "The first 200 million tokens"
- url: https://docs.voyageai.com/docs/pricing
- source_type: primary
- published: unknown
- confidence: high

### [10] Voyage's multimodal embedding trial separately includes 200 million text tokens and 150 billion image/video pixels per account, but subsequent pixels and tokens are explicitly charged.
- quote: "The first 200M text tokens and 150B pixels"
- url: https://docs.voyageai.com/docs/pricing
- source_type: primary
- published: unknown
- confidence: high

### [11] Voyage's free balance cannot be used for Batch API calls and older models receive no free tokens, so an integration must restrict its catalog and prevent batch traffic from being advertised as free.
- quote: "Free token credits do not apply to Batch API usage."
- url: https://docs.voyageai.com/docs/pricing
- source_type: primary
- published: unknown
- confidence: high

## Dead ends
- Fireworks AI proved to be only a $1 signup-credit promotion followed by pay-as-you-go, not a renewable free provider.
- Together AI search results did not yield a current primary-source renewable free tier.
- SiliconFlow documentation confirmed an OpenAI-compatible interface but did not expose sufficiently clear international free-tier, payment, or Germany-availability terms.
- Scaleway's current documentation does not say whether its 1,000,000-token/60-minute allowance resets, so renewal must not be assumed.

## Suggested follow-ups
- Create a fresh German SambaNova account without a payment method and test `/v1/models` plus one production-model completion to resolve the official-document contradiction.
- Ask Scaleway support whether its 1,000,000-token and 60-minute Serverless allowances are lifetime, monthly, or another renewal period, and whether a payment card is mandatory for API activation.
- Verify Jina and Voyage with live keys through LiteLLM v1.97.0 and record response-schema compatibility, dimensions, and account exhaustion behavior.
