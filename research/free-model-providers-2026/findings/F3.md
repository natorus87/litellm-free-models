# F3: Audio-specialist providers offering free API quotas for speech-to-text, text-to-speech, translation, music, or audio generation.

## Findings

### [1] Cartesia has the strongest renewable specialist free tier found: 20,000 credits every month, equivalent to about 27 minutes of Sonic-3.6 TTS or 1 hour 51 minutes of Ink-2 STT, with two concurrent TTS and eight concurrent STT requests.
- quote: "20K credits / month"
- url: https://www.cartesia.ai/pricing
- source_type: primary
- published: unknown
- confidence: high

### [2] Cartesia's free tier is unsuitable for a generally usable commercial proxy because the commercial-use license is explicitly added only by the $5/month Pro tier.
- quote: "Everything in Free, plus Commercial use license"
- url: https://www.cartesia.ai/pricing
- source_type: primary
- published: unknown
- confidence: high

### [3] ElevenLabs exposes a renewable free/pay-as-you-go API allowance spanning TTS, STT, music, sound effects and dubbing; its current free column includes 20,000 Flash/Turbo TTS characters, 4.5 hours of Scribe v2 STT, 2.5 realtime-STT hours and 3 music minutes.
- quote: "Free / Pay as you go"
- url: https://elevenlabs.io/pricing/api
- source_type: primary
- published: unknown
- confidence: high

### [4] ElevenLabs separately offers a selective startup promotion of 12 free months and 33,000,000 TTS characters, so it should be recorded as a grant rather than a generally renewable free tier.
- quote: "12 months free"
- url: https://elevenlabs.io/pricing/api
- source_type: primary
- published: unknown
- confidence: high

### [5] Deepgram offers individual developers a one-time $200 API credit without a credit card or expiration, covering public STT, TTS, Voice Agent and Audio Intelligence endpoints; continued use is pay-as-you-go rather than free-tier renewal.
- quote: "Free $200 Credit then pay-as-you-go"
- url: https://deepgram.com/pricing
- source_type: primary
- published: unknown
- confidence: high

### [6] Deepgram is a particularly viable EU trial integration because it documents GDPR readiness and a dedicated EU processing endpoint at `api.eu.deepgram.com`.
- quote: "We offer a dedicated EU endpoint to ensure data processing stays within the European Union"
- url: https://deepgram.com/pricing
- source_type: primary
- published: unknown
- confidence: high

### [7] Speechmatics provides a no-card $100 one-time credit, after which service pauses unless a card is added; its API covers 55+ STT languages and 69 translation pairs, but this is a trial rather than a renewable free quota.
- quote: "New accounts start with $100 in credit, no card required."
- url: https://www.speechmatics.com/pricing
- source_type: primary
- published: unknown
- confidence: high

### [8] AssemblyAI provides a one-time $50 audio credit for prerecorded transcription, Speech Understanding and streaming STT, then blocks further API usage until the account is upgraded; this is explicitly described as a limited trial.
- quote: "Once you have used the $50 in free credits, you will need to upgrade"
- url: https://support.assemblyai.com/articles/5370767329-can-i-sign-up-for-free
- source_type: primary
- published: 2026-02-27
- confidence: high

### [9] Gladia discontinued its renewable 10-hours-per-month transcription tier in July 2026 in favor of a one-time €50 wallet grant (roughly 80+ prerecorded or 60+ realtime hours), after which users must top up or upgrade.
- quote: "When free credits run out, top up or upgrade to Pro to keep using the API."
- url: https://support.gladia.io/article/credit-based-billing
- source_type: primary
- published: unknown
- confidence: high

## Dead ends
- The initial Deepgram site-restricted search surfaced collateral but not its current pricing page; the official pricing URL was fetched directly.
- Gladia search snippets still advertised the old renewable 10-hour monthly plan, but its current billing migration page supersedes it with a one-time grant.
- No primary evidence found in the allotted searches for a renewable PlayHT API tier.
- Music/audio-generation-only providers beyond ElevenLabs did not surface with sufficiently clear free API terms in the allotted search budget.

## Suggested follow-ups
- Verify Cartesia's free-tier license terms and signup availability from Germany before integration despite the pricing page's commercial-license restriction.
- Test whether ElevenLabs free API keys expose every listed audio endpoint and determine exact per-model credit debits and commercial-use restrictions.
- Check whether Deepgram, Speechmatics and AssemblyAI trial balances permit automated proxy traffic under their API terms.
